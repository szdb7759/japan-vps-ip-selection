## 原生IP vs 住宅IP：这两个概念不是一回事

很多人把"原生IP"和"住宅IP"混着用，其实它们指的是两个维度。

**原生IP** 说的是这个IP归属地：日本本土运营商直接分配的、IP数据库里标注为日本的IP，不是从其他国家广播过来的。对流媒体解锁来说，原生IP基本是硬性要求——Netflix日区、AbemaTV、DMM这些平台会检查IP归属，广播IP直接被墙。

**住宅IP**（也叫ISP IP）说的是IP的类型属性：这个IP是不是标记为"家庭宽带用户"。机房IP在平台风控系统眼里就是"数据中心""托管服务"，住宅IP会被识别成"普通日本家庭用户"。这个区别对TikTok、亚马逊、Instagram这类对账号行为敏感的平台影响很大——平台看到机房IP就会提高审查力度，住宅IP天然信任度更高。

日本VPS市场上常见三种组合：
- **机房原生IP**：日本运营商分配的纯净IP，但属性标记为数据中心。价格最便宜，带宽最大（最高1Gbps），适合建站、流媒体、轻度TikTok。
- **住宅ISP原生IP**（也叫双ISP）：日本本地宽带运营商（比如GLBB、IIJ）分配的家宽IP，同时满足原生+住宅属性。价格贵，但风控通过率高，适合TikTok养号、电商店铺、社媒矩阵。
- **广播IP**（伪原生）：从其他地区广播到日本的IP，虽然显示日本位置，但数据库标记不对，流媒体基本解锁不了。便宜，但用途受限。

这篇文章只讲前两种，第三种直接跳过。
